# Rothad Hanesi — Yeni Bağımsız Site

Bu proje eski `rothadhanesi.github.io` sitesinden bağımsızdır.

## GitHub Pages
1. GitHub'da yeni bir repository oluştur: `rothad-hanesi`
2. Bu klasördeki tüm dosyaları repository'nin köküne yükle.
3. Settings → Pages → Deploy from a branch → `main` / `root` seç.
4. Site adresi: `https://KULLANICI_ADIN.github.io/rothad-hanesi/`

## Discord
Site içindeki Discord butonu `https://discord.gg/uGWhqzA2U` bağlantısına bağlıdır.
